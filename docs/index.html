Everything you watch, read and listen to — in one place.

Films, TV, books, audiobooks, music, podcasts and games. Import years of history from the services you already use, and get recommendations built from your own ratings rather than a popularity chart.

View the code Run your own

This page is documentation, not the app. My Media is self-hosted: it runs on your own machine or your own hosting, with your library in a SQLite file you control. GitHub Pages can only serve static files, so the app itself cannot run here — DEPLOY.md takes about five minutes.

What it does

Logs properly

Rewatches, rereads and per-season TV stack under one title instead of cluttering the list. Half-star ratings, dates, reviews and progress.

Imports without duplicating

Eleven services, auto-detected from whatever you drop in — whole ZIPs included. Re-import the same export later and only the new rows land.

Explains its recommendations

Works from how far above your own average you rate each genre, director, author and decade. Every pick says why.

Remembers what people tell you

A separate inbox for things you've been recommended, with who suggested it and the reason. Logging it closes the loop.

Needs no API keys

Artwork and metadata from Open Library, Apple, MusicBrainz, TVmaze, Wikipedia and Wikidata. TMDB is an optional upgrade.

Keeps your data yours

One SQLite file on your own disk. Nothing leaves it except the metadata lookups needed to fetch artwork.

Running it

git clone https://github.com/Dusky-Nembrotha/my-media.git
cd my-media
npm install --no-bin-links
npm run build
npm start                 # http://localhost:4123

Needs Node 22.5 or newer. For a public URL with a password on it, see DEPLOY.md.
